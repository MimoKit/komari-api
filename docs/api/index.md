# 约定与错误码

所有接口共享以下约定。

## 基础信息

| 项目 | 约定 |
| --- | --- |
| Base URL | `https://你的面板域名/api/v1` |
| 方法 | 全部为 `GET`（含 `OPTIONS` 预检支持） |
| 内容类型 | `application/json; charset=utf-8` |
| 时间格式 | ISO 8601，如 `2026-09-26T13:50:00Z` |
| 数据单位 | 字节（流量、内存、磁盘）、百分比（0-100）、秒（uptime） |

## 成功响应

直接返回资源本身，无包装层：

```json
{ "count": 2, "nodes": [ ... ] }
```

## 错误响应

非 2xx 状态码时返回统一结构：

```json
{
  "error": {
    "code": "not_found",
    "message": "node not found"
  }
}
```

## 状态码与错误码

| HTTP | code | 场景 |
| --- | --- | --- |
| 200 | - | 成功 |
| 204 | - | OPTIONS 预检成功 |
| 400 | `invalid_params` | 参数缺失或非法（如 `hours` 超出范围） |
| 403 | `permission_denied` | 面板私有站点模式下未认证 |
| 404 | `not_found` | 节点不存在，或调用者视角下不可见 |
| 500 | `internal_error` | 服务端内部错误 |
| 503 | - | 插件未加载（被禁用或重启中） |

::: tip 隐藏节点返回 404 而不是 403
对匿名调用者，隐藏节点与不存在的节点表现完全一致，避免泄露节点存在性。用令牌调用即可正常访问。
:::

## 私有站点

面板开启「私有站点」后，匿名请求会被面板拦截（403）。令牌调用不受影响。

## 缓存建议

接口响应携带 `Cache-Control: no-store` —— 实时数据永远新鲜，但也意味着每次调用都是实打实的查询。给机器人做轮询时建议：

- 状态卡刷新间隔不低于 30 秒
- 历史记录（`/records`）结果在客户端缓存 1-5 分钟
- 使用 WebSocket 的场景（如实时大屏）可以搭配本接口做 REST 兜底
